## Fix B: client-supplied imageId trusted
`resolveImage` (used by `controllers/ppdtController.js` and `tatController.js`) now returns 403 when:
the id is not a real picture; the id is a premium picture and the caller is not premium; or an `imageToken` is present but not
issued to this user for this picture (HMAC with JWT_SECRET, 6 h expiry). Old Flutter builds sending only `imageUrl` still work
for the free pool. Stored results no longer keep an `imageUrl` (signed URLs expire); `imageId` is stored. The web
ppdt/tat pages and `lib/images.ts` now pass the token.
